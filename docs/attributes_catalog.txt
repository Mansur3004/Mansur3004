================================
SQL: sql/build_internet_funnel_v4.sql.
Первые четыре объекта ниже — используемый контракт источников, не утверждение о полном DDL.
TAS по подтверждению пользователя хранит только последнее состояние. Таблицы прототипа перечислены полностью.
Типы показаны по известному SQL и синтетическому контракту; банковская БД здесь не опрашивалась.
Внешний TQS исторически имеет ключ questionnaire_rk + effective_from_dttm.
Ключ снимка TAS — parent_application_rk + application_rk, без временной части.
level35_product_bp_nm берётся из собственного поля TAS; без заявки или значения — NULL.
Три итоговых RK заполняются -1 при отсутствии сущности. Итог без временных полей версии.
